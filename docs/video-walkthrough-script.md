# Walk·Up — Video Walkthrough Script

Two parts, recorded as screen capture first, voice-over added afterward.

**How to use this script**
- **🎬 SCREEN** = what you do while recording. Do it slowly and leave a 2–3 second pause after each action so the voice-over has room to breathe.
- **🎙 VO** = the narration you'll record later. It's written to be read aloud at a relaxed pace (~150 words/minute).
- **⏱** = rough on-screen duration for that beat. Record each beat a little longer than the line needs; trimming is easier than stretching.
- Record Part 1 and Part 2 as separate takes.

**Before you record (setup checklist)**
- [ ] Spotify Premium account connected (header shows "Spotify ready · your name").
- [ ] Create a demo show with ~4 slots: Host, two Comedians, a Break. Use real, short set lengths (1–2 min) so the timer demo is quick.
- [ ] Pick walk-up songs ahead of time for at least the two comedians; give one a walk-off song and set an end-of-show song.
- [ ] Set one comedian's set length to **1 min** and light warning to **0.5** (or 1) so you can show green → amber → red without waiting.
- [ ] Browser zoom ~110–125%, close extra tabs, mute notifications, use Chrome or Edge.
- [ ] Audio capture: decide whether the song audio is recorded (recommended — it makes the walk-up demo land) and keep your mic off, since the voice-over comes later.
- [ ] (Optional) DMX light plugged in and connected, if you want to show it live. Otherwise show the panel only.

# PART 1 — Building the Show (Edit Mode)

### 1.1 Intro / what this is  ⏱ ~20s
**🎬 SCREEN:** App open on the Edit tab with the demo show loaded. Let the camera sit on the full screen for a moment, then slowly move the cursor across the top bar.

**🎙 VO:**
"Walk·Up is a web app for running a stand-up comedy show. You build the lineup ahead of time, attach a Spotify walk-up song to each performer, and then run the whole night from one screen with a built-in set timer. This first part covers setting up the show. Part two covers running it live."

### 1.2 The top bar  ⏱ ~25s
**🎬 SCREEN:** Hover each item in the header in order: show dropdown → **+ New** → **Duplicate** → **Delete** → **Edit / Live** toggle → **Export / Import** → Spotify status pill.

**🎙 VO:**
"Across the top, you can switch between shows, create a new one, duplicate an existing one, which is handy for a recurring weekly night, or delete one you no longer need. The Edit and Live toggle switches between planning and performing. Export and Import let you back up your shows as a file or move them to another computer. And on the right, you can see your Spotify connection status."

### 1.3 Connecting Spotify  ⏱ ~20s
**🎬 SCREEN:** (If already connected, show the green "Spotify ready" pill. If you want to show the flow, click **Disconnect** then **Connect Spotify**, approve, and return.)

**🎙 VO:**
"To use music, click Connect Spotify and sign in. Playback requires a Spotify Premium account. If you use more than one computer, your shows can also sync to the cloud through your Spotify account, and everything is stored locally first, so it works even with no internet."

### 1.4 Show details  ⏱ ~10s
**🎬 SCREEN:** Click into **Show name**, **Date**, **Venue**; type a name, set a date and venue.

**🎙 VO:**
"Start by naming the show and filling in the date and venue."

### 1.5 The lineup  ⏱ ~35s
**🎬 SCREEN:** Point to the **Lineup** card and the "X slots · Y min planned" counter. Click **+ Comedian**, then **+ Host**, then **+ Break**. Then drag a slot to a new position, and use the **↑ / ↓** arrows on another.

**🎙 VO:**
"The lineup is a list of slots. Add a comedian, a host, or a break with these buttons. The counter shows how many slots you have and how many minutes you've planned, so you can see if the show is running long before it even starts. Drag any slot to reorder it, or use the up and down arrows."

### 1.6 Editing a slot  ⏱ ~25s
**🎬 SCREEN:** Click a comedian slot. The **Edit slot** panel opens. Type a **Name**, show the **Type** dropdown (Comedian / Host / Break).

**🎙 VO:**
"Click any slot to edit it. Give it a name, and choose whether it's a comedian, a host, or a break."

### 1.7 Choosing a walk-up song  ⏱ ~40s
**🎬 SCREEN:** In **Walk-up song**, click the search box ("Search Spotify for a walk-up song…"), type a song, click a result. The song appears with **▶ Preview**.

**🎙 VO:**
"Search Spotify for the walk-up song, and click the result to attach it. Press Preview to hear it."

### 1.8 Start point and walk-up length  ⏱ ~35s
**🎬 SCREEN:** Show **Song starts at (sec)** and **Play walk-up for (sec, 0 = until stopped)**. Type `41` in one, then show `0:41` also works. Set the length to `15`. Press **▶ Preview**.

**🎙 VO:**
"You rarely want a song from the very beginning. Set the start point to wherever the best moment is, and set how long the walk-up should play. You can type seconds, like forty-one, or minutes and seconds, like zero colon forty-one. If you set the length to zero, the song plays until you stop it."

### 1.9 Audition tools  ⏱ ~45s
**🎬 SCREEN:** Click **▶ Preview**. Click the nudge buttons: **−5, −1, −0.5, +0.5, +1, +5**. Click **■ Stop**. Then press Preview again, wait for the moment you like, click **📍 Use current position**; point at the start field updating.

**🎙 VO:**
"Finding the right spot is easy. These nudge buttons move the start point earlier or later and instantly replay from the new spot. Stop ends the preview. And here's my favorite: press Preview, wait until you hear the exact moment you want, then click Use current position, and the start point is set for you."

### 1.10 Suggested cue search  ⏱ ~30s
**🎬 SCREEN:** Click **🔍 Suggested walk-up**. A Google search opens in a new tab; show it briefly, return. Open the **wording dropdown** and show the options (Seconds, Chorus / hook, Big moment).

**🎙 VO:**
"Not sure where the good part is? This button opens a Google search in a new tab, asking where to start the song, already filled in with your clip length. If the answer isn't in seconds, try a different wording from the dropdown. Nothing is sent from the app, and you should always confirm by ear using Preview."

### 1.11 Walk-off song  ⏱ ~25s
**🎬 SCREEN:** Scroll to **Walk-off song** on a comedian slot. Pick a song, set its start and length.

**🎙 VO:**
"Comedians can also have a walk-off song. It plays when you end their set. Hosts and breaks don't use one. Pick it, set the start point and length the same way."

### 1.12 Set length, light warning, notes  ⏱ ~30s
**🎬 SCREEN:** Show **Set length (min)**, **Light warning at (min left)**, and **Notes / intro**. Type a short intro line in Notes.

**🎙 VO:**
"Set the length of the comedian's set in minutes. The light warning is how many minutes before the end the warning should trigger. In the notes field, you can keep the introduction you plan to read, or reminders about the performer. These show up on the live screen too."

### 1.13 End-of-show song  ⏱ ~20s
**🎬 SCREEN:** Scroll to the show-level **closing / end-of-show song** setting. Pick a song and set its start and length.

**🎙 VO:**
"Finally, you can pick an end-of-show song. It plays when you press Next after the last act. That's the lineup built. In part two, we run the show."

*(End of Part 1.)*

# PART 2 — Running the Show (Live Mode)

### 2.1 Switching to Live  ⏱ ~20s
**🎬 SCREEN:** Click the **Live** toggle. Pause on the full Live screen: big performer name, clock, buttons, Next card, Show Clock.

**🎙 VO:**
"When it's showtime, switch to Live mode. This is a full-screen control panel built to be read at a glance from across a dark room. The current performer, their walk-up song, the timer, and the controls are all here."

### 2.2 The three-step flow  ⏱ ~45s
**🎬 SCREEN:** Point to the phase label ("Up next · 1 of 4"). Click **▶ Play walk-up**; label changes to "Walk-up playing" and the song plays. Let it play a few seconds.

**🎙 VO:**
"Each act follows three steps. First, they're 'Up next.' Press Play walk-up and their song starts from the point you chose. Now the label says 'Walk-up playing.'"

### 2.3 On stage — timer starts  ⏱ ~40s
**🎬 SCREEN:** Click **🎤 On stage — start timer now**. The music fades and the big timer starts counting in green. Point to the progress bar and "X left of Y min."

**🎙 VO:**
"When the comedian reaches the mic, press On stage. The music fades out, and their timer starts. It shows time remaining and a progress bar."

### 2.4 Automatic timer start  ⏱ ~25s
**🎬 SCREEN:** On the next act, press **▶ Play walk-up** and let it run on its own. Point to the message "Timer starts automatically when the music stops." Let the walk-up reach its play length and fade; timer starts by itself. Then show the checkbox "Start the timer automatically when the walk-up music stops."

**🎙 VO:**
"You don't even have to press the button. When the walk-up reaches its play length and fades out, the timer starts by itself. You can turn this off with this checkbox if you'd rather start it manually."

### 2.5 Color-coded timer  ⏱ ~40s
**🎬 SCREEN:** Use the 1-minute demo act. Let the clock go green → amber at the warning time → red when it hits zero, then show "Over by 0:xx" counting up.

**🎙 VO:**
"The timer is color-coded. Green means you're fine. At the warning time you set earlier, it turns amber. When time is up, it turns red and shows how far over the performer has gone."

### 2.6 End set, walk-off, and the log  ⏱ ~35s
**🎬 SCREEN:** Click **■ End set**. Walk-off song plays (if set). Show the **Show Clock** card: the set time appears in the log with a green or red difference like "(-0:12)".

**🎙 VO:**
"Press End set, and the walk-off song plays if they have one. The set is recorded in the log with the actual time, and how far under or over it was, so you have a record of the night."

### 2.7 Next up, Back, and Skip  ⏱ ~25s
**🎬 SCREEN:** Point to the **NEXT** card. Click **Skip →**, then **← Back**.

**🎙 VO:**
"The Next card shows who's coming up and their song. If someone cancels or you need to change course, Skip moves ahead, and Back returns to the previous act. The show clock keeps tracking total running time."

### 2.8 Fade out and Panic stop  ⏱ ~30s
**🎬 SCREEN:** Start a walk-up. Click **Fade out**; music fades smoothly. Start another, click **Panic stop**; music cuts immediately.

**🎙 VO:**
"Two safety controls are always visible. Fade out lowers the music smoothly. Panic stop kills it immediately, for when something goes wrong."

### 2.9 Fade length  ⏱ ~20s
**🎬 SCREEN:** Scroll to the **Fade length** card. Drag the slider from 0.5 to 10 seconds, then settle on about 4.

**🎙 VO:**
"One slider controls how long every fade takes, anywhere from half a second to ten seconds. Longer feels smoother. Button presses respond instantly, while the music fades in the background."

### 2.10 Closing song  ⏱ ~25s
**🎬 SCREEN:** Advance through the last act until the screen says "Show complete — That's a wrap 🎤" and shows total running time. Click **▶ Play closing song**; then **■ Fade out closing song**.

**🎙 VO:**
"After the last act, the screen says 'That's a wrap' and shows the total running time. Press Play closing song to send everyone home with your end-of-show music."

### 2.11 Keyboard shortcuts  ⏱ ~30s
**🎬 SCREEN:** Point to the shortcut line under the controls. Press **Space** for next step, **Esc** to fade, **P** to panic.

**🎙 VO:**
"You don't need the mouse. Space or Enter goes to the next step. Escape fades out. P is panic stop. Rapid double-presses are ignored, so a double-click can't accidentally skip an act."

### 2.12 Bluetooth clicker & Stream Deck  ⏱ ~45s
**🎬 SCREEN:** Scroll to **Clicker & Stream Deck buttons**. Click an **Add button** next to an action; press a key; show the "Last key" pill update. Show **Clear** and **Reset to defaults**. Show the extra actions: Skip act, Back one act, Play closing song, Stage light red (test), Stage light off.

**🎙 VO:**
"For hands-free control, pair a Bluetooth clicker or page-turner with your computer. It acts like a keyboard. Click Add button next to any action, press the clicker button you want, and it's assigned. The Last key indicator shows what your remote is sending. A Stream Deck works too: assign a spare function key, then bind it here. Keep the Walk-Up tab in front, since hotkeys only reach the active window."

### 2.13 Stage light (DMX)  ⏱ ~50s
**🎬 SCREEN:** Scroll to **Stage light (DMX)**. Click **Connect light**, pick the port. Show **Start address**, **Test red / green / blue**, **Channel finder**, **Warning flash** setting. If hardware is connected, show the light flashing red at the warning time and staying red at time-up.

**🎙 VO:**
"If you have a DMX stage light, Walk·Up can run it for you. Use a USB-to-DMX cable, and Chrome or Edge. Connect the light, set its address, and use the test buttons to check red, green, and blue. If a color is wrong, the Channel finder lights one channel at a time so you can match it up. During the show, the light flashes red at the warning time, goes off, and turns solid red when time is up, staying on until the next comedian. If the cable gets unplugged, the timer keeps working."

### 2.14 Wrap-up  ⏱ ~20s
**🎬 SCREEN:** Return to the top. Click **Edit**, then **Export**. End on the full app view.

**🎙 VO:**
"That's Walk·Up: build the lineup, pick the walk-up songs, and run the night with a timer, a light, and a clicker in your hand. Export your shows anytime, duplicate them for next week, and enjoy the show."

## Estimated runtime
- Part 1: ~6 minutes
- Part 2: ~7 minutes

## Recording tips
- Do each action, then **pause 2–3 seconds** before the next; narration will be a little slower than your clicks.
- Keep the cursor steady and move it deliberately to what's being discussed.
- Record the music audio on a separate track if your software allows, so you can lower it under the voice-over.
- For the timer demo (2.5), use a 1-minute set and start from "Up next" so you capture green → amber → red without waiting.
- Record the DMX and Bluetooth/Stream Deck sections only if the hardware is present; they stand alone, so you can drop them or shoot them separately.
- Read the VO lines while watching the finished screen recording, and adjust any line that runs longer than its clip.
